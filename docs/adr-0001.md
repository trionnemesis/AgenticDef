# ADR 0001 — Concrete v0.2 contract choices

Status: implemented choices within the supplied specification; security invariants unchanged.

The supplied documents name objects and gates but leave field structure, implementation language, provider and risk vocabulary unspecified. This implementation chooses:

* Python 3.11+, standard-library async orchestration; JSON Schema and PyYAML for contracts. Anthropic transport is an optional httpx dependency.
* Normative schemas reside in `src/agenticdef/contracts/` to ship in the wheel. This replaces only the suggested root `contracts/` location, not its authority.
* The first slice describes `Role`/`ClusterRole` changes with exact before/after versions. Event attributes are untrusted metadata and cannot supply policy.
* Resource scope is a finite set of exact event IDs, full RBAC object tuples, subject IDs and change IDs. There are no wildcard or free-URL semantics.
* Risk vocabulary is `high`, `low`, `unknown`; unresolved states retain `unknown`. This is deliberately smaller than an uncalibrated severity scale.
* Each finding has `claim` and non-empty `evidence_ids`. Drafts exclude runtime-owned IDs, counters, reason and timestamps. The runtime builds those fields.
* Conclusive results require all five exact reads using the four allowed capabilities. Missing a before/after version cannot become a conclusive benign result.
* Schemas cap arrays and strings; total contract input is limited to 128 KiB, each evidence envelope to 8 KiB, working context to 64 KiB and provider response to 64 KiB.
* Replay `policy.yaml` and `expected.yaml` use JSON syntax, which is valid YAML. Their content is operator-controlled. Model fault scripts are separate `model.json` fixtures and never consulted by real-model mode.
* The filesystem is local and operator-controlled. No distributed claiming or automated reclamation. A changed event/policy/provider under an existing key is refused, not silently re-investigated.
* MIT license. GitHub Pages is a static project introduction only; it is not an investigation UI or API.

No new tool, infrastructure authority, live SDK, remediation path or model-mediated authorization was introduced. The user requested all milestones, so execution proceeds sequentially beyond M0 after its gate passes, while preserving the original work-order text.
