01 / THE AUTHORITY BOUNDARY

The model proposes.
The runtime permits.

Policy is never a prompt suggestion. Every model request passes a fixed registry, exact resource scope and a pre-call budget.

02

04

Grounded result

⊘

No shell. No arbitrary HTTP or SQL. No kubectl passthrough. No remediation. Evidence text cannot grant new authority.

03 / START LOCALLY

One checkout.
No cloud credentials.

Python 3.11+. Install dependencies once, then run every replay offline. Inspect the persisted evidence and audit alongside the result.

Full setup and exit codes ↗

agenticdef / quick start

git clone https://github.com/trionnemesis/AgenticDef.git
cd AgenticDef
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev,anthropic]'
python -m pytest -q
replay scenarios --all

Output: explicit statuses, evidence references, budgets and terminal state.
