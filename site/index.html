01 / THE AUTHORITY BOUNDARY

The model proposes.
The runtime permits.

Policy is never a prompt suggestion. Every model request passes a fixed registry, exact resource scope and a pre-call budget.

01

Event & policy

Validate. Claim once.
Load trusted limits.

02

Bounded reasoning

Propose a typed action.
Reserve before calling.

03

Read-only evidence

Allowlisted reads only.
Hash and persist evidence.

04

Grounded result

Validate every reference.
Persist. Terminate.

⊘

No shell. No arbitrary HTTP or SQL. No kubectl passthrough. No remediation. Evidence text cannot grant new authority.

03 / START LOCALLY

One checkout.
No cloud credentials.

Python 3.11+. Install dependencies once, then run every replay offline. Inspect the persisted evidence and audit alongside the result. Missing evidence never silently becomes benign.

.[dev] includes the offline HTTP mocks. Paid model calls require an explicit provider invocation and still use fixture evidence; see the opt-in model setup.

Full setup and exit codes ↗

agenticdef / quick start

git clone https://github.com/trionnemesis/AgenticDef.git
cd AgenticDef
python -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
python -m pytest -q
replay scenarios --all

A fresh temporary output directory is created for each run. Output includes statuses, evidence references, budgets and terminal state. Reusing an explicit output directory returns saved terminal results.

Replay & control boundaries
